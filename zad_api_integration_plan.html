البنية التقنية

دالة جديدة: zad-market-intelligence

Edge Function جديدة تشتغل كـ cron job كل ساعة أو يومياً:

  1. Fetch من 5 APIs (عملات + طقس + أسعار + معادن + متاجر)
  2. Parse وتنظيف البيانات + validation
  3. Store في جداول جديدة (currency_rates, price_index, market_snapshot)
  4. Detect تغييرات مهمة → alert events
  5. Send context جديد إلى zad-brain

الجداول الجديدة

الجدول الهدف الحقول الرئيسية
currency_rates تاريخ أسعار الصرف from, to, rate, timestamp
price_index تاريخ أسعار السلع item_name, price, currency, timestamp
market_snapshot مؤشرات السوق user_id, inflation_index, timestamp
price_alerts تنبيهات أسعار user_id, item_name, alert_type, price_change

أدوات zad-brain الجديدة

الأداة الاستخدام الإرجاع
fetch_current_exchange_rate from/to currencies "1 EGP = 0.031 USD"
check_price_trend item, days {current, avg, trend, change%}
get_nearby_deals category, location [{store, price, savings%}]
get_inflation_forecast category {next_month%, next_quarter%}
